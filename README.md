# Литера

Приватная адаптивная web‑читалка в эстетике коллекционной книжной серии. Книги и прогресс хранятся локально в браузере — без аккаунта, подписки и сервера.

## Возможности

- единый фирменный разворот для EPUB, MOBI, AZW/AZW3, FB2/FBZ, PDF, DOCX, RTF, TXT, Markdown и HTML;
- просмотр CBZ-комиксов и JPG/PNG/WebP/GIF/AVIF в том же интерфейсе;
- коллекционная библиотека, поиск, сортировка и избранное;
- двухстраничный разворот на компьютере и однополосное чтение на телефоне;
- прогресс и оценка времени до конца;
- заметки и сохранение выделенных цитат;
- **ИИ-Цитатник и персональное дообучение**: автоматическое вычленение афоризмов и цитат из книг любого формата с карточной оценкой («Лайк» / «Мимо»), адаптивным обучением на лету (Online SGD) и предобучением на GPU CUDA (RTX 4060);
- четыре темы, настройка кегля, фокус‑режим и горячие клавиши;
- локальное хранение в IndexedDB.

### Обучение и откат ИИ-модели

- Переобучить базовую модель на видеокарте (NVIDIA RTX 4060 / CUDA):
  ```bash
  python3 scripts/train_gpu.py
  ```
- Мгновенный откат в исходное состояние (до добавления ИИ):
  ```bash
  git checkout backup/pre-ai-baseline
  # или из резервной копии:
  # rsync -a --delete /home/ivan/astbooks_backup_pre_ai/ /home/ivan/astbooks/
  ```

Стили и скрипты из загруженных файлов не исполняются: текст очищается и заново набирается средствами «Литеры». DRM-защищённые файлы не поддерживаются.

## Запуск

Нужен Node.js 22.12+ (также поддерживается Node.js 20.19+).

```bash
npm install
npm run dev
```

Проверка и production‑сборка:

```bash
npm test
npm run build
```

Проект рассчитан на статическое размещение в Vercel. Команда сборки — `npm run build`, выходная папка — `dist`.

## Android APK

Android-проект находится в `android/`. Интерфейс и шрифты включены в APK,
интернет для чтения не нужен. Требуются Android 7+ и актуальный Android System WebView.
Системный выбор файлов поддерживает несколько книг. Кнопка «Назад» возвращает на полку.

Для повторной сборки нужны JDK 21, Android SDK 36 и принятые лицензии SDK:

```bash
npm ci
npm run android:apk
```

Укажите `JAVA_HOME` и `ANDROID_HOME` для своей системы. Установочный файл:
`android/app/build/outputs/apk/debug/app-debug.apk` (тестовая подпись, для прямой установки).
Для публикации в магазине требуется отдельная release-подпись владельца.

Под каждой книгой доступно «Обложка и название»: загрузка изображения, размещение,
цвета текстовой обложки, название и автор. Изменения сохраняются локально.
ZIP с одной книгой и ZIP с изображениями распознаются по содержимому.
Архив с несколькими книгами нужно предварительно распаковать.
Список ошибок пакетного импорта можно закрыть вручную.

Проверки браузерных сценариев:

```bash
npx playwright install chromium
npm run test:e2e
```
